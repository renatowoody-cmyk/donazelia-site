Dona Zélia — Política de Privacidade

Este é um aplicativo pessoal, de uso exclusivo do desenvolvedor, sem coleta ou compartilhamento de dados com terceiros.

Os dados acessados (agenda e tarefas do Google) são usados apenas para o funcionamento do assistente pessoal, exclusivamente pela conta do próprio desenvolvedor. Nenhum dado é vendido, compartilhado ou usado para fins publicitários.

Termos de serviço: este aplicativo é fornecido "como está", para uso pessoal e não comercial.
